# APPENDIX C

## User Guide

This section provides instructions on how to access and use the **PCA Hybridization Portal** deployed across PCA field sites in Bohol (Loay, Balilihan, and Loon farms). The system is web-based and accessible through authorized devices for managing and monitoring the region's coconut hybridization activities.

### 1. System Requirements

#### 1.1 Hardware Requirements
* Desktop computer, laptop, or compatible mobile device.
* Camera or scanner (for digital signature capture and profile upload).

#### 1.2 Software Requirements
* Windows 10 or later (for desktop and laptop).
* Modern web browser such as Google Chrome or Microsoft Edge.
* Android 10 or later, or a supported iOS version (for mobile devices).
* Internet Access.

### 2. Accessing the System
* Open a supported web browser.
* Enter the PCA Hybridization Portal system address.
* Log in using the assigned email address, password, and Two-Factor Authentication (2FA) if enabled.
* The system opens the dashboard authorized for the account role.

### 3. User Roles

#### 3.1 Superadmin
* Manage system governance, including users, roles, and field site assignments.
* Monitor system health through comprehensive Audit Logs detailing all system-wide actions.
* View total user counts broken down by role and active vs. inactive user summaries.
* Monitor system-wide record counts across all hybridization data modules.

#### 3.2 Admin
* Provide final noting and approval of reports (multi-stage workflow).
* View the system's full production funnel.
* Perform strategic oversight via Admin Summary Stats.

#### 3.3 Manager
* Access, filter, and analyze data across all field sites (Loay, Balilihan, Loon).
* Review and validate submitted records from field Supervisors.
* Access the "Command Center" dashboard for site comparisons and regional analytics.
* Generate regional reports and view comparative charts.

#### 3.4 Supervisor
* Create and manage field data records restricted exclusively to the assigned field site.
* View field-specific dashboards featuring production charts and yield comparisons.
* Generate and export PCA-formatted Excel and PDF reports for the assigned site.

### 4. Basic Features
* **Field Data Modules:** Comprehensive tracking for Hybrid Distribution, Monthly Harvest, Nursery Operations, and Pollen Production.
* **Approval Workflow:** Multi-stage record validation process (Draft → Prepared → Reviewed → Noted).
* **Automated Reporting:** PCA-formatted Excel and PDF report generation with automated digital signature embedding.
* **Role-Based Access Control (RBAC):** Strict data isolation and access permissions tailored to user roles.
* **Dynamic Dashboards:** Real-time data visualization including Production Ranking, Operations Funnel, and Efficiency Stats.
* **Audit Logging:** Comprehensive tracking of all create, update, and delete actions within the system.
* **User Profile & Security:** Profile management, digital signature uploads (with 3-month security lock), and secure Two-Factor Authentication (2FA) support.
